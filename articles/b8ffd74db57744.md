# アセンブリ言語備忘録

## データの基本単位

1バイトは16進数で2桁で表されます。
また、1バイトを半分にした4ビットの単位を「ニブル」と呼びます。

| 単位名称 | データサイズ | 上位 / 下位の名称 (High / Low) |
| :--- | :--- | :--- |
| **Byte** | 8 bit (1 byte) | - |
| **Word** | 16 bit (2 bytes) | High Byte / Low Byte |
| **Dword** | 32 bit (4 bytes) | High Word / Low Word |
| **Qword** | 64 bit (8 bytes) | High Dword / Low Dword |

## メモリのデータ配置（リトルエンディアン）

アセンブリ言語において、メモリ上のデータは基本的に**リトルエンディアン**という方式で格納されます。
リトルエンディアンとは、**「データの下位バイトから順に、メモリの小さいアドレスへ配置する」**仕組みのことです。
CPUはデータの下位バイトを先に処理することが多いためです。

データ`0x12345678`は以下のようにメモリに配置されます。 
```text
Address: 0x00 | 0x01 | 0x02 | 0x03
Data:    0x78 | 0x56 | 0x34 | 0x12
```

## レジスタ

CPU内部の高速な記憶装置で、データの一時的な保存や演算に使用されます。

### 汎用レジスタ
- **EAX (Extended Accumulator Register)**: 演算の主役。掛け算や割り算、関数の戻り値の格納などにデフォルトで使われます。
- **EBX (Extended Base Register)**: メモリアドレスの基準（ベース）として使われることが多いレジスタです。
- **ECX (Extended Count Register)**: ループ処理（`LOOP`命令など）の際のカウンタとして自動的に減算されながら使われます。
- **EDX (Extended Data Register)**: EAXの補助として、データの入出力や大きなサイズの掛け算・割り算で一緒に使われます。

### 命令ポインタ
- **EIP (Extended Instruction Pointer)**: 現在実行中の命令のアドレスを指すレジスタで、命令実行後に自動的に次の命令のアドレスに更新されます。

### EFLAGSレジスタ（フラグレジスタ）
CPUの状態を表すフラグが格納されるレジスタで、条件分岐や割り込み処理などで使用されます。
代表的なフラグは以下の通りです：

- **ZF (Zero Flag / ゼロフラグ)**: 計算や比較（`CMP`命令など）の結果が `0` になったときに `1` になります。主に「同じ値かどうか」を判定して分岐する際（`JE` など）に使われます。
- **CF (Carry Flag / キャリーフラグ)**: 符号なし計算において、最上位ビットから「桁上がり」や「桁借り」が発生したときに `1` になります。
- **SF (Sign Flag / サインフラグ)**: 計算結果が負（マイナス）になったときに `1` になります。
- **OF (Overflow Flag / オーバーフローフラグ)**: 符号付き計算において、表現できる数値の範囲を超えてしまった（オーバーフローした）ときに `1` になります。

### インデックスレジスタ
主にメモリの連続した領域（配列や文字列など）を操作する際のアドレス指定に使われます。
- **ESI (Extended Source Index)**: データのコピーや比較命令（`MOVS`など）において、ソース（読み取り元）のアドレスを指すレジスタです。
- **EDI (Extended Destination Index)**: データのコピーや比較命令において、宛先（書き込み先）のアドレスを指すレジスタです。

## スタックと関連レジスタ

**スタック**は、関数呼び出しやローカル変数の管理に使用されるメモリ領域です。

- **ESP (Extended Stack Pointer)**: スタックのトップを指すレジスタで、`POP`や`PUSH`命令でスタック操作を行う際に使用されます。
- **EBP (Extended Base Pointer)**: 関数の呼び出し時に、スタックフレームの基準点を指すレジスタで、ローカル変数や引数へのアクセスに使用されます。

## 命令

### メモリアクセス記法

アセンブリ言語では、角括弧 `[アドレス]` を使用してメモリの特定のアドレスにアクセスします。

- `mov eax, [0x1000]`: メモリのアドレス `0x1000` から値を**読み取り**、EAXに格納
- `mov [0x1000], eax`: EAXの値をメモリのアドレス `0x1000` に**書き込む**

括弧がない場合は、レジスタに直接値が格納されます。


### サイズ修飾子（Intel記法）

メモリからデータを読み書きする際、そのメモリ番地を**「何バイト分のデータ（型）として扱うか」**をCPUに明確に伝えるための指示子です。

レジスタへの代入など、レジスタ名（`EAX`なら4バイトなど）からサイズが自動的に確定する場合は省略できますが、値（即値）を直接メモリに書き込む場合など、サイズが曖昧になる命令では記述が必須となります。

#### 主なサイズ修飾子の一覧

`ptr`（Pointerの略）の前につく単語によって、対象のサイズを指定します。

| 記述 | サイズ |
| :--- | :--- | 
| **`byte ptr`** | 1バイト (8 bit) |
| **`word ptr`** | 2バイト (16 bit) |
| **`dword ptr`** | 4バイト (32 bit) | 
| **`qword ptr`** | 8バイト (64 bit) | 

### 具体例と動作の違い

例えば、同じメモリ番地 `[EAX]` を指していても、修飾子が変わることでメモリへの書き込み結果（影響範囲）が変わります。

```assembly
mov byte ptr [eax], 0x12  ; [EAX]の場所に 12 だけを書き込む (1バイト分)
mov word ptr [eax], 0x12  ; [EAX]の場所に 0012 を書き込む (2バイト分)
mov dword ptr [eax], 0x12 ; [EAX]の場所に 00000012 を書き込む (4バイト分)
```

### MOV

```assembly
mov eax, 0x10    ; EAXに16進数0x10を格納
```

### LEA

```assembly
lea eax, [ebx]     ; EBXのアドレスをEAXに格納
```

### ADD

```assembly
add eax, 0x10          ; EAXに16進数0x10を加算
```

### SUB

```assembly
sub eax, 0x10          ; EAXから16進数0x10を減算
```

### INC

```assembly
inc eax                ; EAXを1増加
```

### DEC

```assembly
dec eax                ; EAXを1減少
```

### MUL

```assembly
mul ebx                ; EAXとEBXを掛け算し、結果をEAXに格納
```

### DIV

```assembly
div ebx                ; EAXをEBXで割り、商をEAXに、余りをEDXに格納
```

### NOT

```assembly
not eax                ; EAXの全ビットを反転
```

### OR

```assembly
or eax, 0x1           ; EAXと0x1で論理和を取り、結果をEAXに格納（最下位ビットを1にする）
```

### AND

```assembly
and eax, 0x1          ; EAXと0x1で論理積を取り、結果をEAXに格納（最下位ビット以外を0にする）
```

### XOR

```assembly
xor eax, 0x1          ; EAXと0x1で排他的論理和を取り、結果をEAXに格納（最下位ビットを反転する）
```

### CMP

```assembly
cmp eax, 0x10          ; EAXと0x10を比較し、フラグを更新（EAXは変更されない）
``` 

### TEST

```assembly
test eax, 0x1         ; EAXと0x1で論理積を取り、フラグを更新（EAXは変更されない）
```

### フラグを更新する命令
- 比較命令 (CMP, TEST)
- 算術演算 (ADD, SUB, INC, DEC, MUL, DIV)
- 論理演算 (AND, OR, XOR, NOT)

### 条件付きジャンプ
フラグレジスタの状態に応じて、プログラムの実行を特定のアドレスにジャンプさせる命令です。
```assembly
JZ 0x2000   ; ZFが1のとき、アドレス0x2000にジャンプ
```
* **ZF**: Zero Flag (ゼロフラグ)
* **SF**: Sign Flag (サインフラグ)
* **OF**: Overflow Flag (オーバーフローフラグ)
* **CF**: Carry Flag (キャリーフラグ)
* `\|` は論理和 (OR)、`&` は論理積 (AND) を表しています。

| 命令 | 名称 | 正しい条件式 | エイリアス (別名) |
| :--- | :--- | :--- | :--- |
| **JZ** | Jump if Zero | ZF = 1 | JE (Jump if Equal) |
| **JNZ** | Jump if Not Zero | ZF = 0 | JNE (Jump if Not Equal) |
| **JL** | Jump if Less | SF ≠ OF | JNGE |
| **JLE** | Jump if Less or Equal | ZF = 1 \| SF ≠ OF | JNG |
| **JG** | Jump if Greater | ZF = 0 & SF = OF | JNLE |
| **JGE** | Jump if Greater or Equal | SF = OF | JNL |
| **JC** | Jump if Carry | CF = 1 | JB (Jump if Below) |
| **JNC** | Jump if Not Carry | CF = 0 | JNB (Jump if Not Below) |

### 関数

```assembly
call 0x3000   ; アドレス0x3000にある関数を呼び出す
```

```assembly
ret            ; 関数から呼び出し元に戻る
```

#### x64 での呼び出し規則
引数は４つまでレジスタで渡されます。
それ以降はスタックに積まれます。
引数は以下のレジスタに渡されます。
RCX, RDX, R8, R9
浮動小数点引数は以下のXMMレジスタに渡されます。
XMM0, XMM1, XMM2, XMM3

#### アラインメント
１６バイト境界にスタックを揃える必要があります。
スタックポインタ（RSP）が１６の倍数であることが求められます。
関数呼び出し前に、スタックをアラインメントするために必要な分だけスタックを調整することが一般的です。

```assembly
sub rsp, 40
call 0x3000
add rsp, 40
ret
```

### 文字列命令の接尾語
B (Byte) : 1バイト単位で操作
W (Word) : 2バイト単位で操作
D (Dword) : 4バイト単位で操作
Q (Qword) : 8バイト単位で操作

### MOVSX
```assembly
lea esi, [source]       ; コピー元となるアドレスをESIにロード
lea edi, [destination]  ; コピー先となるアドレスをEDIにロード
movsb                   ; ESIが指す1バイトを符号拡張してEAXに移動
```

### MOVZX
```assembly
lea esi, [source]       ; コピー元となるアドレスをESIにロード
lea edi, [destination]  ; コピー先となるアドレスをEDIにロード
movsb                   ; ESIが指す1バイトをゼロ拡張してEAXに移動
```

### STOSX
```assembly
lea edi, [destination]  ; コピー先となるアドレスをEDIにロード
mov al, 0xFF            ; ALにコピーする値をロード
stosb                   ; ALの値をEDIが指す1バイトにストア
```

### LODSX
```assembly
lea esi, [source]       ; コピー元となるアドレスをESIにロード
lodsb                   ; ESIが指す1バイトを符号拡張してEAXにロード
```
