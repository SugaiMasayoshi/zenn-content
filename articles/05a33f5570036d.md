# 新1年生のためのC環境構築（Windows + WSL2 + VS Code）

この記事のゴールは、Windows上でCの入門課題が動く環境を、できるだけ迷わず整えることです。
理由の説明は後回しにして、手順だけを短く並べます。

## この記事でできること

- WindowsにWSL2(Ubuntu)を導入する
- Cを動かすための基本ツールを入れる
- VS Codeを入れてWSLと連携する

## 前提

- Windows 11

## 全体の流れ

1. WSL2をインストールする
2. Ubuntuを入れて初期設定する
3. Cの開発ツールを入れる
4. VS Codeを入れてWSL拡張を有効にする
5. Hello, Cで動作確認する
6. ファイルの置き場所に注意する

## 1. WSL2をインストールする

PowerShellを管理者で開き、次のコマンドを実行します。
![PowerShellの起動方法](/images/05a33f5570036d/powershell-launch-select.png)
![PowerShellの起動](/images/05a33f5570036d/powershell-launch.png)

```powershell
wsl --install
```

インストールが完了したらパソコンを再起動してください。

:::message
`wsl --install` は次をまとめて実行します。

- WSL/仮想マシンプラットフォームの有効化
- WSL2を既定に設定
- Ubuntuのインストール
:::

詳しく知りたい人向け:
- https://learn.microsoft.com/ja-jp/windows/wsl/install

## 2. Ubuntuを入れて初期設定する

再起動後、Windowsの検索バーから「Ubuntu」を探して起動します。
![Ubuntuの起動](/images/05a33f5570036d/ubuntu-launch.png)

:::details ほかのディストリビューションを入れたい場合
`wsl --install`によりデフォルトでUbuntuが入りますが、ほかのものも選べます。
以下のコマンドで、利用可能なディストリビューションの一覧を確認できます。
```powershell
wsl.exe --list --online
```

たとえば特定のUbuntuを入れたい場合は、次のように指定します。

```powershell
wsl --install -d Ubuntu-22.04
```
:::

初回起動時に、ユーザー名とパスワードの設定を求められます。
パスワードは画面に表示されませんが、入力できています。

:::message
このユーザー名とパスワードはWindowsのものとは別です。
:::

詳しく知りたい人向け:
- https://learn.microsoft.com/ja-jp/windows/wsl/setup/environment

## 3. Cの開発ツールを入れる

Ubuntuのターミナルで、以下を実行します。

```bash
sudo apt update && sudo apt upgrade
sudo apt install -y build-essential gdb
```

ここまでで、Cをコンパイルして動かせる準備は完了です。

## 4. VS Codeを入れてWSL拡張を有効にする
Windows側でVS Codeをインストールします。

- 公式サイト: https://code.visualstudio.com/

インストール後、VS Codeを開き、拡張機能から次を入れます。

- Japanese Language Pack for Visual Studio Code (Microsoft)
- WSL (Microsoft)
![拡張機能の画像](/images/05a33f5570036d/vscode-extensions-a.png)

VS Codeの左下に「><」のアイコンがあるので、そこをクリックして「WSLへの接続」を選びます。
![WSLへの接続アイコン](/images/05a33f5570036d/wsl-connection.png)
![WSLへの接続の選択](/images/05a33f5570036d/wsl-connection-select.png)

WSLに接続できたら、拡張機能から次を入れます。


- Japanese Language Pack for Visual Studio Code (Microsoft)
- C/C++ Extension Pack (Microsoft)
![拡張機能の画像](/images/05a33f5570036d/vscode-extensions-b.png)

これで、VS CodeのターミナルもUbuntuのものになります。

詳しく知りたい人向け:
- https://learn.microsoft.com/ja-jp/windows/wsl/tutorials/wsl-vscode

## 5. Hello, Cで動作確認する

まず、VS CodeでWSLに接続した状態で作業用フォルダを作ります。

1. VS Codeのメニューから「ファイル」>「フォルダーを開く」を選ぶ
2. `\\wsl.localhost\Ubuntu\home\<ユーザー名>` を開く
3. `c-workspace` という新しいフォルダを作成して開く

VS Codeで `main.c` を新規作成し、次を貼り付けます。

```c
#include <stdio.h>

int main(void) {
	printf("Hello, C!\n");
	return 0;
}
```

コンパイルして実行します。

```bash
gcc main.c -o hello
./hello
```

`Hello, C!` と表示されれば成功です。

## 6. ファイルの置き場所に注意する

Linux用のツールは、Linuxのファイルシステム上で使うのが最速です。
WSL内で作業するなら、プロジェクトは次のような場所に置きます。

- WSLのホーム配下: `/home/<ユーザー名>/project`
- Windowsのエクスプローラーから開くなら: `\\wsl.localhost\Ubuntu\home\<ユーザー名>\project`

`C:\Users\...` や `/mnt/c/...` に置くと遅くなることがあります。

WindowsのエクスプローラーからWSLのファイルを見ることもできます。
![WSLのファイルをエクスプローラーで見る](/images/05a33f5570036d/wsl-explorer.png)

## 7. パスとフォルダ移動の基本

パスは「ファイルやフォルダの住所」です。
`\` はWindows形式、`/` はLinux形式で、どちらも左から順に場所をたどります。

WSLでよく使う移動コマンドは `cd` です。

```bash
cd ~
cd /home/<ユーザー名>
cd ~/c-workspace
```

Linuxでは `/` から始まるのが「絶対パス」、それ以外は「相対パス」です。

```bash
cd /home/<ユーザー名>/c-workspace
cd c-workspace
```

今いる場所を確認したいときは `pwd` を使います。

```bash
pwd
```

`..` は「1つ上のフォルダ」です。

```bash
cd ..
```

Windows側のパスは、WSLでは `/mnt/c/` から始まります。

```bash
cd /mnt/c/Users/<ユーザー名>/Desktop
```
